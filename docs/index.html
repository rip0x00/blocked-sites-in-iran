Blocked Sites in Iran

Reference lists of blocked domains around Iran, rebuilt weekly from public measurement and registry sources. Full documentation, method and caveats live in the GitHub repository.

Downloads

  • list.txt — domains confirmed blocked inside Iran (OONI measurements)
  • blocked-from-outside.txt — Iranian-hosted domains (registry data; not per-domain reachability tests)
  • blocked-by-sanctions.txt — foreign services that have blocked Iran (historical, community-reported)
  • lists.json — per-list metadata: source, method, counts, source SHA-256, last sync
  • dist/manifest.json — generated formats (JSON, CSV, AdGuard, dnsmasq, hosts, Clash, Surge, sing-box) with hashes
  • GitHub Actions — validation and sync status

Data license: CC BY-NC-SA 4.0 — see DATA-LICENSE.md in the repository. A listing is a snapshot from source data, not a live connectivity guarantee; a domain missing from a list is usually untested, not necessarily reachable.

سایت‌های فیلترشده در ایران

فهرست‌های مرجع دامنه‌های مسدودشده‌ی مرتبط با ایران که هر هفته از منابع عمومی اندازه‌گیری و رجیستری بازسازی می‌شوند. مستندات کامل، روش و محدودیت‌ها در مخزن گیت‌هاب است. لینک‌های دانلود همان فهرست بالا هستند.
