# Blocked Sites in Iran | سایت‌های فیلترشده در ایران 🇮🇷

A list of domains confirmed to be blocked in Iran — one domain per line, in [`list.txt`](list.txt).

## English

### What is this?

This repository collects domains that are blocked (filtered) in Iran, in exactly the same plain format as [blocked-sites-in-south-korea](https://github.com/wpzzz/blocked-sites-in-south-korea): a single `list.txt` file, one bare domain per line, sorted alphabetically.

**Current size: 773 domains.**

### Source and method

Iran does not publish an official blocklist, so this list is built from real measurements instead of rumours:

- Data comes from [OONI](https://ooni.org) (Open Observatory of Network Interference) probe measurements taken inside Iran, compiled by the [blocked-sites-dataset](https://github.com/Yuix-Networks/blocked-sites-dataset) project.
- A domain is included when, in the most recent month of data (October 2026), OONI **confirmed** blocking (a block page or another censorship fingerprint was observed) in at least **50%** of at least **20** measurements.

### Notes

- Blocking in Iran changes over time. A domain can be blocked, unblocked, or blocked again — this list is a snapshot, not a permanent truth.
- A domain missing from the list is usually **untested**, not necessarily unblocked.
- Found a domain that is blocked in Iran but missing here, or one that works again? Open an issue or a pull request — or message me on Telegram: https://t.me/rip00

## فارسی

### این پروژه چیست؟

این مخزن، دامنه‌هایی را جمع می‌کند که در ایران فیلتر (مسدود) هستند؛ دقیقاً با همان فرمت ساده‌ی پروژه‌ی [blocked-sites-in-south-korea](https://github.com/wpzzz/blocked-sites-in-south-korea): یک فایل `list.txt`، در هر خط یک دامنه، به ترتیب الفبا.

**حجم فعلی: ۷۷۳ دامنه.**

### منبع و روش کار

ایران هیچ لیست رسمی و عمومی‌ای از سایت‌های فیلترشده منتشر نمی‌کند؛ برای همین این لیست به‌جای شایعه و حدس، از روی اندازه‌گیری واقعی ساخته شده است:

- داده‌ها از اندازه‌گیری‌های [OONI](https://ooni.org) (رصدخانه‌ی باز تداخل در شبکه) از داخل ایران می‌آید که پروژه‌ی [blocked-sites-dataset](https://github.com/Yuix-Networks/blocked-sites-dataset) آن‌ها را گردآوری کرده است.
- یک دامنه وقتی وارد لیست می‌شود که در تازه‌ترین ماه داده‌ها (اکتبر ۲۰۲۶)، در دست‌کم **۵۰٪** از حداقل **۲۰** اندازه‌گیری، فیلتر بودنش **تأیید** شده باشد (صفحه‌ی فیلترینگ یا اثر انگشت سانسور دیده شده باشد).

### نکات

- فیلترینگ در ایران دائماً عوض می‌شود؛ دامنه‌ای ممکن است فیلتر شود، باز شود و دوباره فیلتر شود. این لیست یک عکس لحظه‌ای است، نه حقیقت همیشگی.
- نبودن یک دامنه در لیست معمولاً یعنی **تست نشده**، نه اینکه حتماً باز باشد.
- دامنه‌ای را می‌شناسی که در ایران فیلتر است ولی اینجا نیست؟ یا دامنه‌ای دوباره باز شده؟ ایشو یا پول‌ریکوئست بفرست — یا در تلگرام پیام بده: https://t.me/rip00
