# Support

Questions about the lists, the data, or the tools:

- Open a GitHub issue (use the templates for data reports).
- Or message on Telegram: https://t.me/rip00

There is no SLA — this is a volunteer-maintained dataset — but questions
with specifics (which list, which domain, what you observed) get answered
fastest. For security-sensitive reports, see `SECURITY.md` instead.
